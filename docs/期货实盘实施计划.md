# 新增期货实盘板块

## Summary

新增独立“期货实盘”页面，覆盖期货与期货期权。最新月结单提供官方账户和持仓，全部月结单提供成交历史；支持手工补录月末后的成交，并按正式日线收盘价更新当前持仓及历史盈亏。

## Key Changes

- 自动扫描结算单目录并兼容 `.xls`、`.xlsx`，按工作簿内交易月份导入账户快照、月末持仓和成交明细，源文件保持只读。
- 页面打开时先显示缓存，再自动补齐当前相关合约截至最近已完成交易日的正式收盘价和结算价；另设“强制更新”按钮。
- 复用现有期货、期权行情服务及完成交易日过滤规则。夜盘按所属交易日处理，未完成日线不参与正式估值。
- 官方持仓以最新月结单为准；月末后的手工成交形成“月末后变动”和“预计持仓”，不修改结算单。
- 行情失败时保留最后有效数据，并显示缺价合约、失败来源和实际估值日期。

## 页面与盈亏

- 顶部显示客户权益、保证金、可用资金、风险度、当月盈亏、当日盈亏、已实现盈亏、浮动盈亏、累计手续费和累计净盈亏。
- 顶部另行显示与同花顺一致的“全部盈亏（盯市）”：按结算价估值、扣交易手续费但不扣申报费；原累计净盈亏明确标为收盘价口径并扣除全部账户费用。
- **当前持仓盈亏表**按合约和多空方向展示：期货/期权、官方数量、月末后变动、预计数量、持仓均价、最新收盘价、估值日期、当日盈亏、浮动盈亏、已实现盈亏、手续费和累计净盈亏。
- **历史盈亏表**覆盖当前及已全部平仓的合约：首次/最后成交日期、累计开仓量、累计平仓量、剩余多空持仓、已实现盈亏、浮动盈亏、手续费和累计净盈亏；平仓后记录不消失。
- 两张表均可切换期货、期权或全部，并提供账户合计行；不跨不同合约合计手数。
- 当日盈亏为最新完成交易日累计净盈亏相对前一交易日的变化；累计净盈亏为已实现盈亏加浮动盈亏再减手续费。
- 盈亏以金额为正式口径。期货与期权不显示缺乏统一资本基数的简单收益率，账户层面继续显示风险度和资金指标。
- 合约乘数优先由结算单成交额、价格及数量校验取得；无法确认时停止该合约盈亏计算并提示。
- 提供每日账户盈亏趋势以及按合约展开的成交明细，所有金额均可追溯到结算单或手工记录。

## 成交与数据接口

- 手工成交包括日期时间、期货/期权、合约、买卖、开平、价格、数量、成交额或权利金、手续费、平仓盈亏、成交序号、策略和备注。
- 月结单优先按成交序号接管手工记录；无序号时仅接管日期、合约、方向、价格、数量和可用时间唯一匹配的记录，歧义项标记“待核对”。
- 新增独立 SQLite 数据表保存导入记录、月度账户、月末持仓、成交明细和正式收盘缓存，不改动 ETF 实盘数据。
- 默认读取当前 OneDrive 结算单目录，也支持 `FUTURES_STATEMENT_DIR` 和页面目录设置。
- 成交与盈亏表支持按月份、合约、资产类型、来源和核对状态筛选及 CSV 导出。

## Test Plan

- 使用脱敏合成结算单验证两种 Excel 格式、账户数据、期货与期权持仓及成交解析。
- 验证重复同步、文件变化替换、失败回滚、最新月份判断和结算单对账。
- 验证多空开平、加仓成本、超量平仓、手工删除、月结单接管和歧义记录。
- 验证交易日及夜盘归属、收盘增量补齐、未完成日排除、行情失败降级和强制刷新。
- 验证当前持仓表、已平仓历史保留、账户合计及当日、已实现、浮动、累计净盈亏计算。
- 对实际结算单目录做只读核对，并执行完整编译、单元测试和 Streamlit 页面检查。

## Assumptions

- 页面“当日”指最近一个已完成交易日，不一定是自然日今天。
- 正式盈亏只使用已确认的日线收盘价；盘中行情不写入正式缓存。
- 页面关闭期间不运行后台任务，下次打开时自动补齐。
