# 第十五章 组合择时、半仓袖套与空仓承接：run_portfolio_timing_backtest

## 理论

组合择时的工程难点不是"把单标的信号合起来"，而是三件小事：**资金如何切分、日期如何对齐、半仓与承接如何记账**。`fund_rotation_timing.run_portfolio_timing_backtest`（第 523 行起，约 370 行）用一个"袖套（sleeve）"模型回答：每只 ETF 独立钱包、独立账本、独立信号，组合净值 = 袖套净值之和。袖套隔离的好处是任何单标的的失败（停牌、数据缺失）不会传染，坏处是组合层面的"调仓再平衡"不存在——**本项目刻意不做再平衡**：权重只在配置时设定，之后各袖套自我演化（AGENTS.md 的多 ETF 配置模式同样规定"retain symbols…do not rebalance weights when the selected set is unchanged"的精神）。

## 数学原理

设配置 $\{(\text{symbol}_i, w_i, \text{strategy}_i, n_i, \theta_i)\}$，$\sum w_i \le 100$。资金切分 $K_i = V_0 w_i / 100$。对齐：共同日期 $D = \bigcap_i D_i \cap [\text{start}, \text{end}]$（`common_dates.intersection`），**缺失日期不前向填充价格**（reindex 后袖套内部处理）。

策略四型的袖套净值：

- `cash`：$V_t = K_i$（常数）；
- `hold`：首日整手买入后持有，$V_t = C + q P_t$；
- `timing`（默认 follow_state 路径）：复用单标的引擎，初始资金 $K_i$；
- `timing/half_timing`（fresh_buy 或带承接）：走 `_run_delayed_timing_sleeve`。

半仓袖套的建仓（`_run_delayed_timing_sleeve` 中 `long_budget = capital / 2` 一段，约第 206-227 行）：首次有效买入时**两笔单**——长期半仓预算 $K_i/2$ + 择时半仓预算 $K_i - K_i/2$，各按整手取整。之后长期半仓**永不动**，择时半仓跟随信号；`满仓/半仓` 状态即由此而来。后继买入的预算 `timing_budget = cash if not is_half_timing else min(cash, capital / 2)`——半仓袖套的择时腿**永远不会超买超过一半资金**（现金不足时更少）。

一直持有基准的组合形态：$\sum_i P^i_t / P^i_{t_0} \cdot K_i$（各标的从共同区间首日按权重买入），外加现金袖套。

## 当前项目实现

### 校验链（534-611 行）

权重非负、合计 ≤100%（容差 1e-6）、不足 100% 自动补"剩余现金"袖套、策略类型/建仓规则/承接激活规则合法性、承接标的只能用于择时类、承接 ≠ 来源、同标的只能配一次、缺数据报清单。**校验先行**是这台引擎可读性的基础。

### 延迟袖套（`_run_delayed_timing_sleeve`，第 72 行起）

处理 `fresh_buy` 建仓规则与 512890 承接的完整状态机：

- `fresh_entry`（50 万模拟用）：区间首日只有 `原始信号=="买入"` 才建仓；"持有"起步的标的**必须先经历空仓再等下一次买入**（initial_wait_completed 状态）；`follow_state` 则首日按信号仓位直接建仓；
- 首次买入若已有承接仓 → 先卖 512890（reason "首次买入，退出空仓承接标的"）；
- 空仓承接：signal_position==0 时买 fallback；`after_primary_entry` 要求 `has_primary_entry`；`immediate` 允许从未建仓就承接；
- `not activated` 期间的每行也要记净值（纯现金 + 承接仓市值）——**袖套从区间第一天就有净值曲线**。

### 组合层汇总（798-889 行）

- `nav_data`：账户净值 = 各袖套之和；附带每袖套的 `策略持仓：{symbol}` 列（宽表）；
- summary 30 键（第 1 章表已展示真实数字）；`当前ETF仓位(%)/当前现金仓位(%)` 由各袖套 `current_weight` 求和（现金袖套不计）；
- 交易明细统一追加 `标的名称/代码/配置比例(%)` 三列后合并；
- `component_results`：每袖套的 `最新状态/当前理论仓位(%)`——半仓袖套显示"满仓=10%/半仓=5%"。

## 代码分析

**为什么需要两套 timing 路径**（685-731 行的分支树）：

```
if hold: buy_and_hold
elif initial_entry_policy != follow_state OR empty_position_symbol:
    _run_delayed_timing_sleeve      # 延迟建仓/承接袖套
elif timing: run_ma20_timing_backtest   # 标准择时（直接复用单标的引擎）
else (half_timing): hold_nav + timing_result   # 半仓 = hold + timing 两腿相加
```

半仓的 follow_state 路径用 `hold_nav + timing_nav` 相加——长期腿是 buy_and_hold、择时腿是完整单标的回测，两腿各自记账再合并。而延迟袖套的半仓是**单账本内两只份额**（long_shares/timing_shares）。两种形态数学等价（独立钱包 vs 单钱包分账户），但交易明细形态不同：前者交易无"半仓"标签，后者有"首次有效买入，建立长期半仓"这样的 reason。信号帧本身在重构后委托 `ma_timing_core.ma_threshold_states`（第 9 章），分支结构不变。

**对齐的代价**：`common_dates` 取交集意味着任一标的停牌日全体袖套都不记账（reindex 后 NaN 价格行）。ETF 极少停牌，QDII 类偶发——这是"宁可少一天也不假造一天"的选择。

## 潜在错误

1. **fresh_buy 的初始空窗收益不可见**：延迟袖套在"等待建仓"期间净值=现金常数，summary 的"持仓占比"为 0——正确，但用户可能误以为回测起点错误。组件层用 caption 解释初始建仓规则（`portfolio_timing.py` 的说明文字）。
2. `annual_return` 在 `total_return <= -1` 时返回 0.0（第 831 行附近的本地分支）——资金归零的年化显示为 0% 而非 -100%；注意 `core.metrics.annualized_return` 统一库已按 -100% 处理，组合引擎尚未切换到它（第 28 章路线图）。
3. 半仓袖套后继买入的 `min(cash, capital/2)`：若择时腿先卖出产生现金，长期腿的钱永远封在 long_shares 里——现金池共享但预算钳制，长期腿的钱**不会**被择时腿挪用（钳制上限），但也意味着择时腿卖出后的现金可能闲置（不能自动转长期腿）。设计上自洽，但资金效率非最优。
4. `benchmark_nav` 用 `prices.iloc[0]` 归一——若某标的在共同区间首日恰好停牌（NaN），reindex 后 iloc[0] 为 NaN，基准 NaN 传染全列（ETF 场景罕见）。

## 改进方法

- `total_return <= -1` 时显式返回 -100% 并 warning；
- 延迟袖套的"等待建仓"天数加进 summary（`等待建仓天数`），让 fresh_buy 的空窗成本可量化；
- 半仓袖套支持"择时腿现金回流长期腿"的月末再平衡选项（默认关）；
- 基准列对 NaN 首日给出明确报错而非静默 NaN。

## 实际案例

冻结组合（第 1 章全表）在 2025-02-27 → 2026-09-02 的真实重放：总收益 +36.27%、MDD -4.87%、Sharpe 2.02、交易 128 次、胜率 51.61%、累计成本仅 **85.43 元**（10 万本金 1.5 年）——成本占收益比 0.24%，整手+低费率下成本可忽略是这张表的底层事实。

成分截面的"现在"（2026-09-02 收盘后状态）：

```
512890 hold       一直持有  10%
159201 timing     持仓     10%
159501 half_timing 满仓    10%
159655 half_timing 满仓    10%
518850 timing     持仓     10%
513260/588000/510500/159967/159545  空仓  0%×5
→ 当前ETF仓位 50%
```

年度分解：2025 年 +18.93%（MDD -3.13%）、2026 年至 9 月 +14.58%（MDD -4.87%）。与一直持有基准（同期 +25.60%，MDD -12.17%）对照：**超额主要来自 2026 年**——上半年回撤 -4.87% vs -12.17% 的差距就是择时在 5 只空仓袖套上省下的钱（配合第 10 章 2026-07 指数下段 -8%~-12% 的背景阅读）。
