# Investment Dashboard

个人投资分析工作台。

## 本地运行

```bash
cd /home/renne/investment_dashboard
.venv/bin/python -m streamlit run app.py
```

如需本地运行时自动带入 TickFlow API Key，可以先设置环境变量：

```bash
export TICKFLOW_API_KEY="你的TickFlow API Key"
.venv/bin/python -m streamlit run app.py
```

各页面的 TickFlow API Key 输入框会默认读取这个环境变量，仍可在页面里手动覆盖。

## 数据缓存设计

- `data/raw/`: 原始行情 CSV
- `data/processed/`: 计算后的结果 CSV
- `output/`: 手动导出的文件
- `cache.db`: SQLite 元数据和任务记录

首页保持轻量，只展示缓存数据集数量、最近缓存更新时间、最近交易日、今日重点和常用入口；具体分析从左侧页面进入。

## 手动指数更新

「指数监控」页面优先展示本地缓存，不再定时联网。点击「更新指数数据」后，交易中的标的更新一次只读实时报价；A股、港股、日股和境内期货在各自午休期间首次点击时获取一次上午收盘报价，同一页面会话内再次点击不会重复请求。境内期货午间报价保持显示到各自下午交易开始。已缓存当日正式收盘数据的指数直接跳过，只有缺少最新已完成交易日数据的指数才更新正式日线。盘中和午间报价只保存在当前 Streamlit 进程的临时内存中，浏览器刷新后可以恢复，进程重启后自动清空；这些报价不参与MA20计算，也不写入日线历史。指数原始历史保持只追加，另用只追加的收盘确认日线保存已完成交易日；计算时由收盘确认日线覆盖同日盘中旧值，因此不会改写原始历史。累计缓存不足252条时会回补最多1000天历史，MA20从累计历史计算；页面分列报表固定保留最近120个自然日，每个交易日分别展示当时最近一次MA20状态转变日期及从转变日收盘价起算的区间涨幅。指数详情首次读取时会建立独立的本地长历史缓存，后续打开详情不再重复获取全量数据。
任务入口统一在 `services.update_tasks.run_index_ma20_update`，任务记录会写入 `cache.db` 的 `jobs` 表。

## 铁矿石价格微信提醒

`scripts/monitor_iron_ore_price.py` 独立监控铁矿石主连 `I0`。价格首次低于
730元/吨时通过Server酱推送普通微信；价格持续低于阈值时不重复推送，回到
730元及以上后重新布防。脚本只在铁矿石交易时段联网，并将运行状态写入
`output/alerts/`、日志写入 `output/logs/`。

SendKey优先读取环境变量 `SERVERCHAN_SENDKEY`，也可保存到仅当前用户可读的
`~/.config/investment_dashboard/serverchan_sendkey`。配置后可运行
`scripts/install_iron_ore_price_alert_task.ps1`，创建每分钟检查一次的Windows计划任务；
计划任务通过无窗口的 `wscript.exe` 包装器运行，非交易时段会自动跳过。

## ETF组合严格审计

现有组合回测页面保持原有兼容口径；需要核对复权、真实成交、分红、基准公平性、
参数稳健性和样本外表现时，运行独立的增强审计入口：

```bash
.venv/bin/python scripts/run_etf_portfolio_audit.py
```

集中配置位于 `config/etf_portfolio_audit.json`。审计使用前复权价格生成信号，
使用未复权开盘/收盘价成交和估值，并从公开基金分红表单独计入现金分红。
行情和分红缓存在本次输出目录；传入 `--refresh-data` 才重新联网，开发检查可用
`--quick` 跳过完整 Walk-Forward。结果写入
`output/etf_portfolio_audit_20260727/`，包括所需 CSV、数据质量报告、结论报告和交互图表。

## 已网站化的桌面脚本

分析类页面统一采用“左侧分析设置、右侧数据输入/上传/执行”的布局，减少不同页面之间的操作差异。

- 「指数监控」：展示上证指数、主要宽基指数（含科创 50 和中证 2000）、微盘股、恒生科技、恒生港股通高息低波、纳斯达克 100、VIX、日经 225、韩国 KOSPI，以及中证 500、中证 1000、铁矿石、沪金、原油、沪银期货主连的最新摘要和固定四列仪表盘卡片；下方按 MA20 偏离率排序的汇总表不包含 VIX。摘要卡片和正式日线的批量联网更新均由「更新指数数据」按钮触发；已完成且已缓存的收盘数据不会重复获取。六个期货主连名称会附带当前实际合约，并在手动更新成功后重新识别和保存。原油主连实时价和 2026-07-10 起的日线统一采用东方财富 `142.scm` 口径，来源校正数据独立缓存，不覆盖此前积累的原始历史。点击指数名称可查看长历史走势、回撤和最近数据；详情页仍按长历史缓存规则只补取缺失日期。
- 「A股分析」：场外基金输入代码后拉取东方财富累计净值；场内基金/股票输入代码后通过 TickFlow 拉取日收盘价；也支持上传 CSV/Excel 作为备用入口。图表包含均线、RSI、涨跌幅、滚动年化收益率和回撤分析，并计算波动率、价格百分位、最大回撤波段、修复天数和年度最大回撤。
- 「策略回测」：支持单标的 MA20 择时、多ETF配置择时和多基金动量轮动。多ETF配置择时可逐行设置ETF代码、配置比例、一直持有/纯择时/半仓持有半仓择时/现金、均线周期和触发阈值；配置比例不足100%时剩余部分自动作为现金，超过100%时报错，比例为0%的行保留在编辑表中但不参与本次回测，并与相同比例全部一直持有进行对比。页面支持上传多个基金/ETF 文件，或输入场内基金/ETF代码通过 TickFlow 获取前复权/后复权日线，也支持输入场外基金代码通过东方财富获取累计净值。回测按用户选择的开始、结束日期运行，数据获取会在后台尽量保留完整历史，并使用区间开始前的数据完成 MA 和动量预热；结果同时列出近一年、今年来、近三年、近五年和成立来的实际区间、收益与交易胜率。胜率仅统计已经卖出的交易，按扣除买卖手续费后的实际盈亏判断；交易明细会显示卖出时的本次盈亏金额和盈亏率。MA20 择时每次运行都会默认通过 TickFlow 联网更新，失败时才回退本地缓存；多ETF配置择时和多基金轮动默认复用缓存，可勾选「联网更新数据」重新拉取。MA20 择时默认带 1% 触发阈值，按当日收盘价高于 MA20 上方阈值买入、低于 MA20 下方阈值卖出，并按收盘价成交；“一直持有收益”固定按所选回测区间第一个实际交易日到最后一个实际交易日计算，不受均线周期影响。回测指标将策略净值回撤明确标为“策略最大回撤”，MA20 择时同时显示同一区间的“一直持有最大回撤”；策略回撤、波动率和夏普均从初始资金开始计算，包含首日手续费与滑点。轮动策略按 22 个交易日动量做满仓轮动，默认使用盘后固定价模式：调仓日收盘后用当日收盘价计算动量，并按同一收盘价模拟换仓，不计交易所滑点但保留手续费；该模式假设委托全部成交，且2026-07-06之前的历史结果属于按当前规则模拟。页面仍可切换为“前收盘信号、次日开盘成交”的旧模式，旧模式对场内ETF计入买入 +0.05%、卖出 -0.05% 滑点。持仓数大于 1 时只卖出退出名单的标的、只买入新进入的标的，共同持仓保留且名单不变时不做权重再平衡，未参与实际买卖的标的缺少成交价不会拖延调仓。场外基金及没有开盘价的数据按累计净值或收盘价近似成交，场外基金不套用整手限制。页面输出策略与一直持有对比的净值走势、回撤分析、交易明细、每日持仓金额和摘要。
- 「相关性分析」：支持上传 CSV/Excel，或通过 TickFlow 获取 A 股 ETF、美股日线，并支持期货主连数据。A 股 ETF、美股、期货主连和上传文件可以混合输入，统一放入同一个矩阵两两计算。不同标的按共同日期自动对齐，起点自然取最晚开始有数据的标的日期，再计算收盘价或日收益率 Pearson 相关系数 r；历史分析结果会持久化保存并在页面下方按资产类别合并展示，例如 A 股 ETF/股票、美股、期货主连各自一张矩阵，同一对标的只保留最新结果，新计算会直接更新对应类别矩阵。若同类矩阵存在缺失项，页面会优先用本地缓存自动补全，不会主动联网拉取。
- 「持仓分析」：内置固定持仓清单，包含 ETF 512890、159201、159545、513260、159655、159501、518850、588000、159915、510500、159967，铁矿石期货价差 I2609 - I2701，以及 I2609P730、I2609P740、I2609P750、I2609P760 期权。ETF 使用完整基金名称，页面代码只显示六位代码，不显示交易所后缀。页面打开时先展示本地缓存；A股交易日9:30至15:05点击「加载持仓信息」时，使用TickFlow实时报价批量更新上方卡片，并在正式日线缓存落后时只补齐此前已完成的交易日；当天盘中报价不写入日线缓存，也不参与下方择时计算。盘前、休市日和15:05后使用日线增量更新。交易日15:05后，页面打开期间会自动检查并获取一次当日正式收盘日线，写入只追加缓存后更新「ETF择时状态」表；旧版本遗留的同日盘中缓存必须经过收盘确认后才能用于该表。期货价差和期权仍随加载按钮更新。页面下方仅汇总 ETF，并按类似指数监控 MA 排序表的格式展示：513260、159915、588000 使用 MA20/1%，510500 使用 MA15/1%，159201 使用 MA20/0.5%，159655、159501、159967 使用 MA25/2%，159545 使用 MA10/1%，518850 使用 MA30/1.5%；价格处于上下阈值之间时延续前一状态。159655、159501 按“半仓持有、半仓择时”显示仓位判断，择时份额退出时仍显示“半仓”；159201、159545、518850、513260、588000、159915、510500、159967 为纯择时。512890 作为长期持有标的，不参与择时判断，也不在「ETF择时状态」表中显示。页面最下方根据正式收盘日线重建近7个自然日内的仓位转换记录，盘中报价不参与操作指引。
- 「期货价差」：输入多个期货合约，优先通过 TickFlow 拉取日线数据，计算“基准 - 其他”的绝对价差。
- 「美股分析」：输入 AAPL、MSFT、COWZ 等美股代码，通过 TickFlow 拉取日线收盘价，复用均线、RSI、滚动年化收益率和回撤分析，并支持本地缓存与增量更新。参数区、顶部摘要、图表 Tab 顺序和回撤分析样式与「A股分析」保持一致。
- 「微盘股」：从东方财富 BK1158 板块获取成分股，按总市值升序展示微盘股名单；页面默认优先复用本地缓存，只有勾选「联网刷新数据」或暂无缓存时才联网获取。联网刷新时保存 BK1158 真实成分快照，并基于真实快照展示第 200 名市值和微盘 20 均值。均值和第 200 名统计会剔除停牌股，不再提供当前成分历史回溯估算。脚本 scripts/update_microcap_snapshot.py 可用于定时保存当天真实成分快照。
