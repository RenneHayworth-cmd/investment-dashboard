# Investment Dashboard

个人投资分析工作台。

## 本地运行

```bash
cd /home/renne/investment_dashboard
.venv/bin/python -m streamlit run app.py
```

如需本地运行时自动带入 TickFlow API Key，可以先设置环境变量：

```bash
export TICKFLOW_API_KEY="你的TickFlow API Key"
.venv/bin/python -m streamlit run app.py
```

各页面的 TickFlow API Key 输入框会默认读取这个环境变量，仍可在页面里手动覆盖。

## 数据缓存设计

- `data/raw/`: 原始行情 CSV
- `data/processed/`: 计算后的结果 CSV
- `output/`: 手动导出的文件
- `cache.db`: SQLite 元数据和任务记录

期货实盘还会在 `cache.db` 中保存月结单导入结果、月末账户与持仓、成交明细、逐日资金流水、账户级手工日盈亏、期权到期事件和正式收盘/结算价。券商源结算单始终只读。

首页保持轻量，只展示缓存数据集数量、最近缓存更新时间、最近交易日、今日重点和常用入口；具体分析从左侧页面进入。

## 指数更新

「指数监控」页面优先展示本地缓存。Windows计划任务每天15:10和16:10各检查一次：15:10补齐A股、日盘期货及当时已收盘市场的正式数据，16:10补齐港股并重试仍有缺口的项目。后台任务只更新已完成交易日的正式日线；已缓存目标交易日的指数直接跳过，周末和休市无缺口时不联网。已打开的页面每30秒只检查一次本地缓存版本，发现定时任务完成后自动重绘上方卡片和下方MA20，该页面检查不会联网。点击「更新指数数据」仍可手动更新：交易中的标的获取一次只读实时报价，A股、港股、日股和境内期货在各自午休期间首次点击时获取一次上午收盘报价。盘中和午间报价只保存在当前 Streamlit 进程的临时内存中，不参与MA20计算，也不写入日线历史。指数原始历史保持只追加，另用只追加的收盘确认日线保存已完成交易日；计算时由收盘确认日线覆盖同日盘中旧值，因此不会改写原始历史。累计缓存不足252条时会回补最多1000天历史，MA20从累计历史计算；页面分列报表固定保留最近120个自然日，每个交易日分别展示当时最近一次MA20状态转变日期及从转变日收盘价起算的区间涨幅。页面下方MA20汇总表同时显示上一状态转换时间，以及从上一转换日收盘价到当前转换日收盘价的完整上一区间涨幅。

计划任务可通过 Windows PowerShell 安装（不需要打开 Codex 或 Streamlit）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File \\wsl.localhost\Ubuntu\home\renne\investment_dashboard\scripts\install_index_ma20_update_tasks.ps1
```

任务日志保存在 `output/logs/index_ma20_scheduled.log`；单实例锁会防止15:10和16:10的任务重叠。计划任务会通过 WSL 登录 shell 读取非交互环境中的 `TICKFLOW_API_KEY`，但不会复用页面输入框中的密钥；未加载密钥时会在日志中明确说明并使用免费/公开数据源，不记录密钥内容。

「任务与数据」页面也提供“更新缺失的正式指数数据”入口；首次点击只读取本地缓存，列出截至目标日期最近20个交易日内的缺口、预计更新范围和数据源，二次确认后才联网更新。更新完成后会尽可能用独立日线源复核同一目标交易日的收盘价，复核结果不覆盖正式缓存；没有可靠独立来源的品种会明确标为无法复核。该入口只补齐已经完成的交易日，不获取盘中卡片报价。任务入口统一在 `services.update_tasks.run_index_ma20_update`，任务记录会写入 `cache.db` 的 `jobs` 表。

CSV 缓存写入使用同目录临时文件、文件锁和原子替换；SQLite 元数据写入失败时会恢复原文件，避免并发页面或计划任务读取到截断数据。

场内基金、ETF和股票统一使用明确的五种复权参数：前复权（差值）、前复权（比例）、后复权（差值）、后复权（比例）和不复权。普通“前复权”默认指差值口径，以便与东方财富、同花顺保持一致；比例口径仅作为复现旧结果的明确选项。新版行情缓存使用带版本和复权方式的独立键，例如 `fund_close_v2_159545.SZ_forward_additive`，不再回退到旧口径缓存。不复权正式收盘按日期只追加；复权缓存更新时先比较近期重叠交易日，价格不变只追加新日期，分红等事件导致历史回溯变化时才全量重建该标的。重建失败会保留最后可用的卡片价格，但暂停该标的择时信号、操作指引及512890承接判断。

新版缓存迁移命令默认只读预览，只有传入 `--apply` 才从环境变量读取 `TICKFLOW_API_KEY`、串行联网并写入：

```bash
.venv/bin/python scripts/migrate_fund_price_caches.py
.venv/bin/python scripts/migrate_fund_price_caches.py --apply
```

需要比较差值与比例前复权对现有参数的影响时，可运行 `.venv/bin/python scripts/audit_fund_adjustment_impact.py`；报告只做口径审计，不自动调整均线、阈值、仓位或组合权重。

## 铁矿石价格微信提醒

`scripts/monitor_iron_ore_price.py` 独立监控铁矿石主连 `I0`。价格首次低于
730元/吨时通过Server酱推送普通微信；价格持续低于阈值时不重复推送，回到
730元及以上后重新布防。脚本只在铁矿石交易时段联网，并将运行状态写入
`output/alerts/`、日志写入 `output/logs/`。

SendKey优先读取环境变量 `SERVERCHAN_SENDKEY`，也可保存到仅当前用户可读的
`~/.config/investment_dashboard/serverchan_sendkey`。配置后可运行
`scripts/install_iron_ore_price_alert_task.ps1`，创建每分钟检查一次的Windows计划任务；
计划任务通过无窗口的 `wscript.exe` 包装器运行，非交易时段会自动跳过。

## ETF组合严格审计

现有组合回测页面保持原有兼容口径；需要核对复权、真实成交、分红、基准公平性、
参数稳健性和样本外表现时，运行独立的增强审计入口：

```bash
.venv/bin/python scripts/run_etf_portfolio_audit.py
```

集中配置位于 `config/etf_portfolio_audit.json`。审计使用前复权价格生成信号，
使用未复权开盘/收盘价成交和估值，并从公开基金分红表单独计入现金分红。
行情和分红缓存在本次输出目录；传入 `--refresh-data` 才重新联网，开发检查可用
`--quick` 跳过完整 Walk-Forward。结果写入
`output/etf_portfolio_audit_20260727/`，包括所需 CSV、数据质量报告、结论报告和交互图表。

## 已网站化的桌面脚本

分析类页面统一采用“左侧分析设置、右侧数据输入/上传/执行”的布局，减少不同页面之间的操作差异。

- 「指数监控」：展示上证指数、主要宽基指数（含科创 50 和中证 2000）、微盘股、恒生科技、恒生港股通高息低波、纳斯达克 100、VIX、日经 225、韩国 KOSPI，以及中证 500、中证 1000、铁矿石、沪金、原油、沪银期货主连的最新摘要和固定四列仪表盘卡片；下方按 MA20 偏离率排序的汇总表不包含 VIX。正式日线在15:10和16:10由后台计划任务自动补齐，也可由「更新指数数据」手动触发；盘中只读卡片报价仍只由手动按钮获取。已完成且已缓存的收盘数据不会重复获取。六个期货主连名称会附带当前实际合约，并在手动更新成功后重新识别和保存；汇总表的 MA20、偏离率和状态转换使用当前具体合约的独立正式日线，避免主力换月时混合两个合约价格。原油主连实时价和 2026-07-10 起的主连日线统一采用东方财富 `142.scm` 口径，来源校正数据独立缓存，不覆盖此前积累的原始历史。点击指数名称可查看未复权主连长历史走势、回撤和最近数据；详情页仍按长历史缓存规则只补取缺失日期。
- 「A股分析」：场外基金输入代码后拉取东方财富累计净值；场内基金/股票输入代码后通过 TickFlow 拉取日收盘价，默认采用前复权（差值），并保留比例复权等明确选项；也支持上传 CSV/Excel 作为备用入口。图表包含均线、RSI、涨跌幅、滚动年化收益率和回撤分析，并计算波动率、价格百分位、最大回撤波段、修复天数和年度最大回撤。
- 「策略回测」：支持单标的 MA20 择时、多ETF配置择时和多基金动量轮动。多ETF配置择时可逐行设置ETF代码、配置比例、一直持有/纯择时/半仓持有半仓择时/现金、均线周期和触发阈值；配置比例不足100%时剩余部分自动作为现金，超过100%时报错，比例为0%的行保留在编辑表中但不参与本次回测，并与相同比例全部一直持有进行对比。页面支持上传多个基金/ETF 文件，或输入场内基金/ETF代码通过 TickFlow 获取日线，默认采用前复权（差值），比例复权作为复现旧结果的独立选项；也支持输入场外基金代码通过东方财富获取累计净值。回测按用户选择的开始、结束日期运行，数据获取会在后台尽量保留完整历史，并使用区间开始前的数据完成 MA 和动量预热；结果同时列出近一年、今年来、近三年、近五年和成立来的实际区间、收益与交易胜率。胜率仅统计已经卖出的交易，按扣除买卖手续费后的实际盈亏判断；交易明细会显示卖出时的本次盈亏金额和盈亏率。MA20 择时每次运行都会默认通过 TickFlow 联网更新，失败时才回退本地缓存；多ETF配置择时和多基金轮动默认复用缓存，可勾选「联网更新数据」重新拉取。MA20 择时默认带 1% 触发阈值，按当日收盘价高于 MA20 上方阈值买入、低于 MA20 下方阈值卖出，并按收盘价成交；“一直持有收益”固定按所选回测区间第一个实际交易日到最后一个实际交易日计算，不受均线周期影响。回测指标将策略净值回撤明确标为“策略最大回撤”，MA20 择时同时显示同一区间的“一直持有最大回撤”；策略回撤、波动率和夏普均从初始资金开始计算，包含首日手续费与滑点。轮动策略按 22 个交易日动量做满仓轮动，默认使用盘后固定价模式：调仓日收盘后用当日收盘价计算动量，并按同一收盘价模拟换仓，不计交易所滑点但保留手续费；该模式假设委托全部成交，且2026-07-06之前的历史结果属于按当前规则模拟。页面仍可切换为“前收盘信号、次日开盘成交”的旧模式，旧模式对场内ETF计入买入 +0.05%、卖出 -0.05% 滑点。持仓数大于 1 时只卖出退出名单的标的、只买入新进入的标的，共同持仓保留且名单不变时不做权重再平衡，未参与实际买卖的标的缺少成交价不会拖延调仓。场外基金及没有开盘价的数据按累计净值或收盘价近似成交，场外基金不套用整手限制。页面输出策略与一直持有对比的净值走势、回撤分析、交易明细、每日持仓金额和摘要。
- 「策略回测·年度动态组合」：默认从2019年起以50万元一次性投入，按上一年末前最多五个日历年的可得数据，以实际交易日70%/30%拆分筛选和验证，在版本化 `config/annual_etf_registry_v1.csv` 与 `config/annual_etf_index_families.json` 范围内逐年选择ETF及MA10/15/20/25/30、0%-2%阈值。注册表只含快照日仍上市产品，页面明确披露生存者偏差。流程为本地缓存只读预检、二次确认后分批联网补齐、单独运行回测；旧ETF等待退出信号后迁往最新年度目标，同ETF连任时新参数从新年首个交易日收盘生效。主结果按同日收盘、单边万0.6、100份整数手模拟，并对比年度选择一直持有、全部持有512890及次日收盘压力结果；页面展示年度选择、资格、参数、交易、迁移、方向收益/风险贡献和失败明细，并支持CSV与Markdown下载。
- 「相关性分析」：支持上传 CSV/Excel，或通过 TickFlow 获取 A 股 ETF、美股日线，并支持期货主连数据。A 股 ETF、美股、期货主连和上传文件可以混合输入，统一放入同一个矩阵两两计算。不同标的按共同日期自动对齐，起点自然取最晚开始有数据的标的日期，再计算收盘价或日收益率 Pearson 相关系数 r；历史分析结果会持久化保存并在页面下方按资产类别合并展示，例如 A 股 ETF/股票、美股、期货主连各自一张矩阵，同一对标的只保留最新结果，新计算会直接更新对应类别矩阵。若同类矩阵存在缺失项，页面会优先用本地缓存自动补全，不会主动联网拉取。
